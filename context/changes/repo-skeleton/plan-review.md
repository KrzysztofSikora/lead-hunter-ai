## Decisions the PR reviewer should look at
- D-4: the refusal checks only that the hash is present, so `placeholder` is accepted until S-01. The README tells the operator to use a placeholder.
- D-3: these are the operator-facing variable names, and unknown variables are ignored (see finding 9).
- D-6: the DB file name and dev location differ from tech-stack.
- D-9: the health contract is public and drives the compose healthcheck.
- D-11: the redaction path list (should be `costly`, finding 2).

## What is good
- The end state is concrete and observable, and every bullet maps to a test or an agent check with saved evidence.
- The library claims I spot-checked hold: the `fastify-type-provider-zod@7.0.0` peers match `npm view`; `@fastify/static` 10.1.7 hides its routes from swagger by default (`schema.hide = opts.schemaHide ?? true`), so the OpenAPI comparison is not polluted; the `.gitignore` cite (22 lines) and the absence of `data/` are accurate.
- The layer rules respect `app.ts`/`server.ts` (infrastructure is injected through `deps`), and a lint fixture test proves them.
- The risks name the sandbox network, Playwright download and `source`-condition fallbacks up front, each with a conservative deviation path.
- The scope is disciplined: no auth, router, query library or domain tables leak in.
