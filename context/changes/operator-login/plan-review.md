## Decisions the PR reviewer should look at
- D-5: deny-by-default guard. Correct only if it keys on the matched route, not the raw URL (finding 1).
- D-4: one global throttle key. Anyone who can reach the port can lock the operator out for 15 minutes, and a restart resets it.
- D-6: `Secure` is never set in the Docker deployment (peer is the bridge gateway). Option B is the one-function alternative.
- D-2: loopback without a hash starts, but login answers 503. Check that this matches how the operator expects dev to work.
- D-1: custom `scrypt:` string format instead of PHC (because Compose interpolates `$`). It is a persisted config format, so it is hard to change later.
