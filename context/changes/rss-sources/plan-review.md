## Decisions the PR reviewer should look at
- D-9 / D-5: a health check takes up the per-source interval, so a check blocks a run for 1 h.
- D-7: a synchronous run route can hold a request for up to about 2 minutes (see #12).
- D-13: our own entity decoding and tag stripping for untrusted feed XML/HTML (a security-relevant choice).
- D-20: how real feed content is anonymised before it is committed as fixtures.
- D-4: the `ingest` refactor shared with manual import (identity behaviour of a done slice).
