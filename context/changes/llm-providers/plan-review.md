## Decisions the PR reviewer should look at
- D-3: whether a paid unknown-price model is blocked (differs from the roadmap's "brak danych"), and whether paid answers without usage run uncapped.
- D-4: cross-provider reuse by prompt and schema version only, plus the new `reused_from_analysis_id` column.
- D-7: the structured-output schema transform (`oneOf`, `maxItems`, `pattern`) is the main risk on the Anthropic path.
- D-8: SDK retries also retry timeouts, which can mean paid and uncounted duplicate calls.
- D-10: public route plus the `analysis_force` column; non-forced "retry" on a COMPLETE row means a rescore, not a new call.

## What is good
- Findings are grounded: the port, runner, repository, contract (`AnalysisServiceStatus` `provider: z.enum(['mock'])`), env schema, lint driver list and the `MockAgent` setup all exist as described.
- The error model (D-9) never stores SDK messages, stops the drain on errors that affect the whole provider, and has a key-echo check and a TR-12 canary test.
- Budget money is kept in integer micro-USD with ceil rounding, and the month boundary is in Warsaw time, consistent with S-04 D-9.
- Every AC has a named integration test against `MockAgent`. Real providers are human checks with evidence, as the test plan requires.
- Out of scope is explicit (drafts, raw-signal/draft limits, streaming, caching), and the migration is additive.
