## What is good
- Every covered AC (FR-02 AC1–AC4, FR-06 AC1–AC3, FR-11 AC1, FR-12 AC1) and the restart requirement has a named integration or e2e assertion. TR-06 gets a table-driven canonicalisation test.
- The canonicalisation rules follow the roadmap's *Decided up front* list exactly. Option B (sort parameters, strip `www.`) is rejected for the right reason.
- The scope is tight: no `sources` table, no fetching, no TanStack Query. Each deferral has a reason and a named owner (S-09, S-10/S-12, S-06).
- The schema changes are additive, nullable where the value is unknown, and use the existing module/port/repository pattern and lint layers.
- The e2e login budget (4th of 5) and the 2-spec budget were checked against `e2e/smoke.spec.ts`.
- The human checks include a prompt-injection/XSS paste, which matches the rule that source content is untrusted data.
