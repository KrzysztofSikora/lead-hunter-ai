## Decisions the PR reviewer should look at
- D-1: public response shape (costly). Kept isolated in `packages/contracts/src/digest.ts`, which is fine, but it fixes the API surface for FR-29 later.
- D-3: the 7-day window and the open-status set decide what the operator sees each morning; together with finding 1 it decides whether Today can 500.
- D-8: the brief honours only `minScore`, against FR-10 AC6's full filter list (finding 4).

## What is good
- Grounding is solid. Nearly every cited file, line and symbol exists as described (`followUpsDue`, `startOfWarsawDay`, `DEFAULT_MIN_SCORE`, `isDemo`, the mock's null tokens, `JobCost` tokens only, the eslint layering rule).
- Cost reads "brak danych" with tokens, never an estimate (FR-09 AC4), and S-05/limit work is deferred explicitly as follow-ups.
- The weak-signal split uses evidence level as well as category, which matches §7.3 and FR-16 AC3. Scoring stays deterministic and the selection is pure and testable.
- The evidence-run restore step respects the lesson "A gate run must not rewrite committed files".
- Scope is tight: one route, one module, one page, no new spec, no notifications or export.
